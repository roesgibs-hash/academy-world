# Academy World 3.0 CLEAN

Este paquete es una reconstrucción completa. No es un parche de versiones anteriores.

## Subida recomendada a GitHub Pages
1. Vacía el contenido anterior del repositorio o súbelo a una rama nueva.
2. Sube **el contenido de esta carpeta**, respetando exactamente la estructura.
3. El archivo `index.html` debe quedar en la raíz.
4. En GitHub > Settings > Pages usa la rama `main` y carpeta `/ (root)`.
5. Espera el despliegue y abre la web.
6. En Sistema > Diagnóstico pulsa **Ejecutar diagnóstico**.
